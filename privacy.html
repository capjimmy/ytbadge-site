개인정보처리방침

YTBadge · 최종 수정일 2026년 10월 24일

YTBadge(이하 "본 앱")는 사용자의 컴퓨터에서 실행되는 윈도우 데스크톱 프로그램입니다. 본 방침은 본 앱이 어떤 정보를 다루고, 어디에 저장하며, 누구에게 전송하는지를 설명합니다.

1. 핵심 요약

본 앱은 사용자의 데이터를 개발자에게 전송하지 않습니다. 개발자가 운영하는 서버는 없습니다. 모든 데이터는 사용자 본인의 컴퓨터와, 사용자 본인의 구글· 유튜브 계정 사이에서만 오갑니다.

2. 접근하는 정보

사용자가 구글 로그인으로 권한을 허용하면, 본 앱은 YouTube Data API v3를 통해 사용자 본인의 채널에 대해 다음을 수행합니다.

항목용도
채널 정보, 영상 목록처리할 영상을 파악
영상별 조회수, 길이어떤 뱃지를 붙일지 판정
영상 썸네일 이미지원본 보관 및 합성
썸네일 변경합성한 이미지를 업로드

사용 범위(scope)는 https://www.googleapis.com/auth/youtube 하나입니다. 시청 기록, 구독자 개인정보, 댓글, 수익 정보에는 접근하지 않습니다.

3. 저장 위치

  • 설정·영상 목록·실행 기록: %APPDATA%\YTBadge\ytbadge.db
  • 원본 썸네일 사본: %APPDATA%\YTBadge\originals\
  • 사용자가 지정한 뱃지 이미지 사본: %APPDATA%\YTBadge\badges\
  • 실행 로그(7일 보관): %APPDATA%\YTBadge\logs\

전부 사용자 컴퓨터 안에만 있으며, 외부로 전송되지 않습니다.

4. 로그인 토큰

구글 로그인으로 발급된 토큰은 윈도우 자격 증명 관리자(Windows Credential Manager)에 저장됩니다. 평문 파일로 저장하지 않으며, 개발자는 이 토큰을 볼 수 없습니다. 프로그램에서 연결을 해제하거나 자격 증명 관리자에서 항목을 삭제하면 즉시 제거됩니다.

구글 계정 권한은 사용자가 직접 철회할 수 있습니다: myaccount.google.com/permissions

5. 제3자 제공

본 앱은 사용자 데이터를 제3자에게 판매·대여·공유하지 않습니다. 광고 모듈, 분석 도구, 사용 통계 수집 기능을 포함하지 않습니다.

네트워크 통신은 다음 두 곳으로만 발생합니다.

  • 구글 / 유튜브 API 서버 — 위 2항의 작업 수행
  • i.ytimg.com — 공개된 썸네일 이미지 내려받기

6. 데이터 삭제

%APPDATA%\YTBadge\ 폴더를 삭제하면 본 앱이 저장한 모든 데이터가 사라집니다. 프로그램을 제거하려면 설치 폴더를 삭제하고, 자동 실행을 켜 두었다면 윈도우 작업 스케줄러에서 YTBadge\Sync 작업을 삭제하면 됩니다.

7. 구글 API 서비스 사용자 데이터 정책

본 앱의 구글 API 사용은 Google API Services User Data Policy를 따르며, 여기에는 제한된 사용 요건 (Limited Use requirements)이 포함됩니다.

8. 변경

본 방침이 변경되면 이 페이지에 수정일과 함께 게시합니다.
